# Darksite VIP

A modern, dark-themed website with a sleek design and interactive features. This project showcases a VIP membership platform with various sections including inventory, supporters, pricing, and contact information.

## Features

- Responsive design
- Interactive navigation
- Smooth scrolling
- Image sliders
- Video background
- FAQ section
- Social media integration
- Contact form
- Newsletter subscription

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Custom animations and transitions

## Setup

1. Clone the repository
```bash
git clone https://github.com/Rommelisnotgay/Darksite-vip.git
```

2. Open `index.html` in your browser

## Sections

- Home - Welcome section with video background
- Inventory - Featured items and benefits
- Supporters - Showcase of VIP supporters
- Ask Me - FAQ section
- Pricing - Membership plans
- Contact - Social media links and contact form
